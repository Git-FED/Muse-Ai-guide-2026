# Muse Data Diet

A disciplined workspace for understanding recurring work, estimating usage, finding redundancy, and cutting low-value activity safely.

## Rules

- Audit before cutting.
- Use estimates honestly when exact data is unavailable.
- Rank high to low impact.
- Separate duplicated work from necessary safeguards.
- Require double confirmation before a consequential cut.
- Verify the cut afterward.
- Never put credentials or raw private logs in this workspace.
