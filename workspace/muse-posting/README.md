# Muse Posting Workspace

Prompts and operating notes for preparing safe, platform-aware Muse posts.

## Workflow

1. Confirm the source content and approved image.
2. Verify platform image support and limits.
3. Chain the approved URL through the intended workflow.
4. Review the full pipeline before publishing.
5. Apply the posting rules and record evidence.

Do not store credentials, private tokens, or account secrets in this workspace.
