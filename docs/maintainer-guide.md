# Maintainer Guide

## What to maintain

- Keep the lesson sequence coherent.
- Keep every lesson’s six-file structure intact.
- Prefer small, reviewable changes.
- Remove stale examples and date-sensitive claims.
- Keep learner-facing instructions separate from maintainer notes.
- Review links, assets, accessibility, privacy, and promo references before release.

## Release checklist

1. Run the lesson structure tests.
2. Run the link checker.
3. Run the promo-presence check.
4. Review the rendered site navigation.
5. Inspect changed images and diagrams.
6. Read the release notes as a learner.
7. Build the archive from tracked, non-secret files.

## What else can be added

- Answer keys and facilitator notes
- Accessibility transcripts and alt-text audits
- Small project exemplars
- Versioned learning outcomes
- Translation files
- Learner feedback summaries
- A glossary of recurring terms
