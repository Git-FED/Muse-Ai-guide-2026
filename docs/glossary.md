# Glossary

- **Agent:** A system that can plan or take bounded actions.
- **Context:** Information supplied to interpret a task.
- **Guardrail:** A rule limiting unsafe behavior.
- **Prompt:** An instruction given to Muse.
- **Tool:** An external capability.
- **Verification:** Checking whether output or action is correct.
