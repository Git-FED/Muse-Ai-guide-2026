# Prompt Design Guide

A strong Muse prompt makes the desired outcome and the verification method visible.

## The six-part prompt

1. **Role:** What perspective should Muse use?
2. **Goal:** What result is needed?
3. **Context:** What information matters?
4. **Constraints:** What must be included or avoided?
5. **Format:** What should the response look like?
6. **Check:** How will the result be evaluated?

## Improve a vague prompt

Instead of: “Make this better.”

Use: “Rewrite this for [audience] in [tone], preserve [facts], remove [problem], keep it under [limit], and list the changes afterward.”

## Teach verification

Ask learners to identify assumptions, request evidence when claims matter, compare output to the original goal, and record what they revised.
