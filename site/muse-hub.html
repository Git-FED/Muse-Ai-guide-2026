Learning path

Each lesson is designed to move from explanation to demonstration, guided practice, independent revision, and reflection.

Prompt Lab

Prompt anatomy

Role → Goal → Context → Constraints → Format → Check

Make the output and its quality test explicit. This is the six-part pattern taught across the guide.

Revision move

“Keep / Change / Why”

Instead of restarting, preserve the useful structure, name the exact change, and explain the reason.

Boundaries

Say what Muse may not do

Examples: only search attached files; read but do not reply; draft but do not publish.

Background work

Make activity inspectable

Use goals, activity views, permissions, and explicit approval points. A useful agent is capable and reviewable.

Agent coordination anti-loop checklist
  • One explicit next speaker
  • Unique turn identifier
  • Ignore already-processed turns
  • Maximum turn count or deadline
  • Stop phrase and human override
  • Evidence of completion before closing

Data diet

Track burn like money: audit, rank, cut carefully, verify.

01–04

Find the waste

Audit recurring tasks, estimate usage, rank high-to-low, and identify duplicate work.

Open workspace
05

Cut with double confirmation

State exact scope, savings, impact, risk, and rollback. Confirm twice before a consequential cut.

06–07

Track and verify

Report allowance first, show deltas and pace, then verify that the cut actually reduced noise or usage.

The goal is not minimum activity. The goal is maximum useful signal per unit of attention and usage.
